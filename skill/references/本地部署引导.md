## 第 1 步：装 lark-cli 并登录飞书

### 1.1 安装 lark-cli
```bash
npm install -g @larksuite/cli
# 或按官方文档：https://github.com/larksuite/cli
```

### 1.2 登录授权
```bash
lark-cli auth login
```
跟着提示在浏览器完成飞书授权。**授权用用户自己的飞书账号**，能访问他自己的表格/文档即可。

### 1.3 ⚠️ Agent 环境里必须剥离 HERMES_* 环境变量
如果 lark-cli 报错 `hermes context detected but not bound`，说明它检测到了 Agent 上下文。
**解决办法：调用前剥离所有 `HERMES_` 前缀的环境变量。**
```python
import os, subprocess
EXE = "<你的 lark-cli 可执行文件绝对路径>"
env = {k: v for k, v in os.environ.items() if not k.startswith("HERMES_")}
def lark(*args):
    return subprocess.run([EXE] + list(args), capture_output=True, text=True, env=env)
```
> 在 bash 里可以建一个 wrapper 脚本剥离后再调用，省得每次手写。

### 1.4 验证
让用户给一个自己的飞书表格链接，跑：
```bash
lark wiki +node-get --node-token "<表格URL>"
```
返回 obj_token = 通了。

## 第 2 步：部署抖音解析 API

达人数据来自抖音解析服务。**推荐用开源项目自部署**（不要把别人的服务当依赖）：

- 项目：**Douyin_TikTok_Download_API**（作者 Evil0ctal，Apache-2.0）
  https://github.com/Evil0ctal/Douyin_TikTok_Download_API

### 2.1 部署（二选一）

**A. 本地跑**（最简单，够用）
```bash
git clone https://github.com/Evil0ctal/Douyin_TikTok_Download_API.git
cd Douyin_TikTok_Download_API
python -m venv venv
# Windows: venv\Scripts\activate   |  Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
python start.py
```
默认跑在 `127.0.0.1:8000`，API 文档 `http://127.0.0.1:8000/docs`。

**B. 服务器上跑**（要长期在线选这个）
用其自带 Dockerfile / docker-compose.yml，或 `bash/install.sh` 一键部署。端口配置在 `config.yaml` 的 `API.Host_Port`。

### 2.2 ⚠️ 必须填自己的抖音 Cookie（最容易卡住的一步）
抖音有风控，**不填 Cookie 什么都拉不到**。手把手：
1. Chrome 打开 https://www.douyin.com 并登录
2. 按 F12 → Network 标签 → 刷新页面
3. 点任意一个请求 → Request Headers 里找 `Cookie:`
4. 整行值复制（很长，一串 `xxx=yyy; zzz=www;`）
5. 粘贴进 `crawlers/douyin/web/config.yaml` 的 `Cookie: ""` 引号中间
6. 重启服务生效

> ⚠️ Cookie = 账号登录凭证，只放本地/自己服务器，别发给任何人、别提交 git。

### 2.3 如果在远程服务器上——开 SSH 隧道
```
ssh -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -N -L 18000:127.0.0.1:8000 <你的服务器别名>
```
本机访问 `http://127.0.0.1:18000`。
> 坑：隧道空闲十几分钟会被对端 reset，加保活参数；起隧道后先探测连通再批量拉。

### 2.4 验证
```bash
curl "http://127.0.0.1:8000/docs" -s -o /dev/null -w '%{http_code}'
```
200 = 通了。

## 第 3 步：接回达人筛选主流程

两边都通之后，**立刻进入实际工作**：
1. 跟用户要**飞书表链接**（不要自己去 grep 找 token）
2. `wiki +node-get` 解析 → `sheets +csv-get` 读表头，**当次**核对评审列字母
3. 用 API 拉达人资料+作品（见 SKILL.md 接口说明）
4. 按评估标准出标签/评估/建议
5. `+cells-set --writes @file` 写回，写回后读回验证
