# 收敛到"最新官方口径"：PDF 版本比对 + 文案硬信息溯源

适用：甲方给了一套"旧策划文档/对标分析法"，又给了(s)份官方培训 PDF(常 `/file/` 上传、文件名带日期如 `课件260826.pdf`)，要你统一成一份可用于写作的正确口径。

## 常见问题结构
甲方文山：① 策略/策划文档(可能署名"XX科技·品牌专项服务团队"，内容常是**竞品爆款拆解**产生的框架/镜头分析法) + ② 官方培训课件 PDF。你写正式内容**只能信②**，①的判断方法可留、①里的成分/功效/证书/专利/价格全是疑似借壳素材，要逐条在②里找官方出处，找不到=作废或等用户确认。

## 关键坑 & 判断
- **策划文档(③来自竞品拆解)的硬信息几乎不可信**：成分、功效数字、证书字号、专利号常是竞品(案例:白云山/林清轩)画面上的素材被搬来当"品牌卖点"。识别信号：同一定位/字样的专利号在文档里前后几个版本对不上(YL 年份/末几位不一致)、帧图 alt 出现别的品牌名。框架/元镜头/镜头节奏这类方法论安全可复用。
- **官方课件版本也可能互相冲突**：用户会连给两份同一产品线的培训 PDF(桌面版 vs 飞书最新版)。不要只读最新的就完事，**逐页 diff 找出确切差异**，否则说不清"新版到底改了哪"。用 pymupdf 读文本逐页比对。
- **"没提 X"（用户说的）≠ "砍掉 X"**。用户看到新版某卖点词消失(案例: 肽)、问"是不是不要肽了"，其实那份课件反而讲得更全——真相常是**同产品线两款分工叙事**：产品A(油)走胶原叙事、产品B(膜)走肽叙事；"肽"并没删，是被归到另一款去了。diff 后再回答，别顺着用户猜。

## 做法：逐页 diff
pymupdf(`fitz`)逐页 `get_text()`，规范化空白 `' '.join(t.split())` 后比对本页字符串，打印只有哪几页不同 + 每页首行做 coverage 检查(看是否缺整段产品)。
```python
import fitz
def pages_all(p):
    d=fitz.open(p); return {i+1:' '.join(pg.get_text().split()) for i,pg in enumerate(d)}
old=pages_all(r"旧.pdf"); new=pages_all(r"新.pdf")
for pg in range(1,len(new)+1):
    if old.get(pg)!=new.get(pg): print("diff P",pg)
```
对"某卖点词是否还在/移到哪"的问话，再对全文跑关键词位置定位(`re.finditer('肽', t)` 列页码)，确认是删除还是位移。

## 收敛产物
产出一份 `references/` 或项目目录下的 markdown 写作口径，列清：
- 唯一权威来源 + 以哪版为准(文件名带日期更可信=较新)，旧版差异在哪几页
- 每款产品的: 名称/昵称/定位口号/技术/功效维度/成分(各贴官方讲法)/适用场景/用法/Q&A诚实点/合规边界
- **可安全引用清单** vs **⚠️数据门槛项**(原料/第三方测试数据、专利"仅展示介绍不代表功效"铁律) vs **作废项**(旧策划里的竞品专利号/功效数字/未官方背书的策划价格)
- 专利写法定式: 原料专利仅作展示介绍用，不能当功效背书
